# Development Scripts

This directory contains development and build-time scripts for the Village Storefront platform.

## Scripts

### `export-theme-tokens.ts`

Exports tenant theme tokens from the database to CSS and JSON formats for use with Tailwind and Qute templates.

**Purpose:**
- Generate tenant-specific CSS custom properties for runtime theming
- Export theme data as JSON for programmatic access
- Create a theme index mapping subdomains to theme files

**Usage:**

```bash
# Export all tenant themes
npm run theme:export

# Export specific tenant theme
npm run theme:export -- --tenant-id=<tenant-uuid>

# Custom database URL
ts-node scripts/dev/export-theme-tokens.ts --database-url=postgresql://user:pass@host:5432/db

# Custom output directory
ts-node scripts/dev/export-theme-tokens.ts --output-dir=./custom/path
```

**Output Files:**

The script generates the following files in the output directory (default: `modules/core-platform/src/main/resources/templates/storefront/_generated`):

- `_theme-{subdomain}.css` - CSS custom properties for each tenant
- `theme-{subdomain}.json` - JSON representation of theme tokens
- `theme-index.json` - Index mapping subdomains to theme files

**Example Output (`_theme-demo.css`):**

```css
/**
 * Tenant Theme: demo
 * Auto-generated by export-theme-tokens.ts
 * DO NOT EDIT MANUALLY
 */

:root {
    /* Primary Colors */
    --color-primary-50: #eff6ff;
    --color-primary-100: #dbeafe;
    --color-primary-200: #bfdbfe;
    /* ... */
}
```

**Integration with Storefront:**

Once the `tenant_theme` table is implemented in a future migration:

1. Run the export script: `npm run theme:export`
2. Update `StorefrontResource.buildThemeTokens()` to load from generated files
3. Include tenant-specific CSS in the Qute template head section

**Current Status:**

⚠️ The `tenant_theme` table does not yet exist in the database schema. The script currently uses mock data for development and testing. Once the table is added in a future iteration, the SQL query at line ~85 should be uncommented and used.

**Dependencies:**

- `pg` - PostgreSQL client for Node.js
- `ts-node` - TypeScript execution environment
- `@types/node` - TypeScript type definitions

Health check script that waits for PostgreSQL to be ready before continuing with other operations.
