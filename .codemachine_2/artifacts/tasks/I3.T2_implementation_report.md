   - Fields: reason (required), refund (optional boolean)
   - Validation: reason max 500 chars
   - Used by `POST /admin/orders/{id}/cancel`

3. **RefundOrderRequest.java**
   - Fields: amount (Money, required), reason (required), restockItems (optional boolean)
   - Validation: amount must be valid Money object, reason max 500 chars
   - Used by `POST /admin/orders/{id}/refund`

4. **RefundResponse.java**
   - Fields: refundId, amount, status (PENDING/SUCCEEDED/FAILED), reason, createdAt, processedAt
   - Returned by refund operations

5. **OrderSummary.java**
   - Lightweight order representation for lists
   - Fields: orderId, orderNumber, status, customerEmail, total, itemCount, timestamps
   - Used in paginated order lists

6. **OrderListResponse.java**
   - Paginated wrapper: items (List<OrderSummary>), pagination (PaginationMetadata)
   - Used by `GET /orders` and `GET /admin/orders`

#### Promotion DTOs

7. **PromotionDto.java**
   - Complete promotion details
   - Fields: id, code, discountType, discountValue, currency, minimumOrderAmount, maximumDiscountAmount, usageLimit, usageCount, perCustomerLimit, startDate, expiryDate, status, description, timestamps
   - Used for GET responses

8. **PromotionRequest.java**
   - Create/update promotion
   - Validation: code pattern `^[A-Z0-9_-]+$`, max 50 chars; discountValue must be positive
   - Used by `POST /admin/promotions` and `PATCH /admin/promotions/{id}`

9. **ApplyPromotionRequest.java**
   - Simple wrapper for promotion code
   - Fields: promoCode (required, max 50 chars)
   - Used by `POST /api/carts/current/promotions`

10. **PromotionListResponse.java**
    - Paginated wrapper: items (List<PromotionDto>), pagination
    - Used by `GET /admin/promotions`

#### Cart DTOs

11. **CartListResponse.java**
    - Paginated wrapper: items (List<CartDto>), pagination
    - Used by `GET /admin/carts`
