### ⚠️ **BLOCKED: Integration Tests**

#### **Issue Description**

`TenantFilterTest.java` cannot execute due to a Quarkus 3.17.5 classloading bug:

**Error:**
```
java.lang.NoClassDefFoundError: io/quarkus/vertx/http/runtime/VertxHttpBuildTimeConfig
  at io.quarkus.deployment.configuration.BuildTimeConfigurationReader.initConfiguration
```

**Root Cause:**
- Quarkus `QuarkusTestExtension` attempts to load build-time configuration class `VertxHttpBuildTimeConfig`
- This class exists only in deployment JAR (`quarkus-vertx-http-deployment`), not runtime JAR
- Test classpath doesn't include deployment JARs by design
- This is a known Quarkus bug in version 3.17.5

**Attempted Fixes:**
1. ❌ Added `quarkus-vertx-http-deployment` to test scope → No effect
2. ❌ Removed explicit `quarkus-vertx-http` dependency → No effect
3. ❌ Disabled QuarkusTestProfile → Still fails
4. ❌ Configured Dev Services in test properties → Still fails
5. ❌ Cleaned Maven cache and rebuilt → Still fails
6. ❌ Upgraded to Quarkus 3.30.6 → Breaks compilation (`InjectMock` removed)
